# 表情包图库（自备）

本仓库**不附带任何表情包图片**。原因：表情包多为网络传播素材，来源与授权不明确，不便随代码分发。

## 目录约定

在 `D:\QQat\stickers\` 下按标签建子目录，目录名就是模型看到的标签：

```
stickers/
  笑/          a.gif  b.jpg
  无语/        c.png
  可爱/        d.webp
```

- 支持 `png / jpg / jpeg / gif / webp / bmp`
- 最多扫两层目录
- 平铺文件按文件名前缀取标签：`笑_01.png` → `笑`
- 扫描结果缓存 60 秒；加完图等一分钟，或重载插件

## 可选：标签语义

在 `stickers/manifest.json` 里写每个标签的适用场景，插件会把它喂给模型，选图更准：

```json
{
  "categories": {
    "笑": { "description": "用于大笑、调侃、看乐子的场景" },
    "无语": { "description": "用于无奈、说不出话、对方太离谱时" },
    "可爱": { "description": "卖萌、夸奖、撒娇的场景，低频使用" }
  }
}
```

## 模型怎么用

工具 `qqbot_send_sticker`：

- `tag`：按标签随机挑一张
- `name`：精确指定文件名（用户点名要某张时）
- 都不传：全库随机

插件在系统提示里会告诉模型「像群友那样偶尔发，别刷屏，没有贴切的不发」。
